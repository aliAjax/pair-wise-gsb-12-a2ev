# 车辆调度小工具

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

数据保存在浏览器 localStorage 中，方便后续扩展接口、权限、图表或地图能力。

## 排班规则

1. **任务字段**：计划起止时间、货物重量（吨）、配送区域、配送任务、绑定车牌/司机。
2. **车辆记录**：车牌号、载重上限（吨）、绑定司机。
3. **司机记录**：姓名、可跑区域（多选）。
4. **新建任务**：
   - 先选配送区域，候选车辆只列出「绑定司机可跑该区域」的车；
   - 再检查同一车牌计划区间是否重叠（半开区间 `[开始, 结束)`，首尾相接不算冲突）；
   - 有冲突时任务整体顺延到该车全部冲突任务之后；若顺延后仍重叠则继续顺延，卡片上展示「顺延区间」与顺延时长；
   - 区域不符或货物重量超过车辆载重上限时，保留表单填写内容并提示具体原因，**不写入排班列表**；
   - 车牌未登记时同样保留内容、提示先登记车辆，不写入列表。
5. **持久化与展示**：车辆、司机、任务统一存于 localStorage（key：`dfwlfront-3-dispatch-v2`），重新打开后按车牌分组、同车任务按计划开始时间先后排列；旧版 `dfwlfront-3-dispatch` 数据会自动迁移。
